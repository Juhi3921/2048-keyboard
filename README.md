but the condition is while playing user can only use keyboard keys

- New tiles appear after every valid mov

- For new game user have to refresh page

## Controls

| Key | Action |
|-----|--------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
| Enter | Close Game Over message |
